sqwen 只针对 qwen35moe 一个架构族：Gated DeltaNet 线性注意力 + 全注意力 + MoE。整模型（Q4_K_M，20.2 GiB）常驻单张 24 GB 显卡，对外是 OpenAI 兼容的 HTTP API。

01 · 上下文成本

上下文为什么几乎不花钱

KV cache 用 q4_0 量化，K/V 都是，只覆盖 10 个全注意力层：每 token 占 5.6 KiB。GDN 线性注意力层的状态是固定大小，不随序列增长。所以 -c 从 172K 拉到 200K，速度只慢 0.4%。

一句话：上下文吃的是显存，不是算力。

02 · 测量

投机解码：更深是净亏

MTP 头自带起草能力。直觉上草稿越长越赚，实测相反：一个草稿 token 的边际成本 ≈ 一次完整 decode 的 60%（校验要多读它激活的专家权重），而接受率随位置衰减（pos0≈0.9，pos1≈0.7）。同机 greedy、ABBA 交替：

每步草稿decode
0（不投机）125–130 t/s
1145–147 t/s
2125 t/s
3106 t/s

最优点就是每步 1 个草稿。引擎在线实测「0 / 1」两种模式并锁定胜者（--spec-adaptive，默认开），而不是靠拍参数：每个候选取 5 轮样本，跳过前 32 步（约 45 token）后才探测，按吞吐中位数比较。

对 llama.cpp：ABBA 台账

同机、同会话、两边 ggml-cuda.dll 完全相同、ABBA 交叉、都走 HTTP server、greedy、生成 1200 token：

项目sqwenllama.cpp比值
Decode，MTP（每步 1 草稿）137 t/s151 t/s对方快 1.10×
Prefill pp512~3,000 t/s~3,200 t/s对方快 ~5%
启动（纯加载）12.3 s19.2 s—
172K 上下文显存23,676 MiB24,083 MiB—

测量纪律：跨会话的绝对值会漂 ±5%，只有同会话、同 DLL 的 A/B 才可信。decode 落后 ~10%，prefill 打平，显存更省；投机解码对两边收益相当（各 ~+7%），差距没有被投机放大。

03 · 接口

OpenAI 兼容端点

端点说明
POST /v1/chat/completionsOpenAI 兼容；流式 + 非流式，tool calling
GET /v1/models · GET /health列模型 / 就绪检查（端口在模型预热完成后才绑定）
GET /内置 WebUI
POST /v1/bench快速跑分端点

Tool calling：工具定义渲染进 chat template，生成后从文本里抽 tool_call——与 llama.cpp 同一条路线。流式下工具调用在最后一个分片整块发出，支持多轮 role: "tool" 结果。

Prompt cache：前缀复用 + GDN 状态检查点。多轮对话首字延迟约好 11 倍。

sqwen.exe server "E:\models\BigBang-v1.i1-Q4_K_M.gguf" \
  --port 8100 -c 172032 -b 2048 -u 512 -t 8 \
  --template "E:\models\chat_template_v22.5.jinja" \
  --spec-type draft-mtp \
  --temp 0.1 --top-k 40 --top-p 0.95 --min-p 0.05 \
  --repeat-penalty 1.08 --repeat-last-n 128 \
  --reasoning on --reasoning-effort medium --reasoning-budget 2048 \
  --reasoning-format deepseek --queue-capacity 8
# --repeat-penalty 1.08 --repeat-last-n 128 不要省：默认 1.0 等于关闭，
# 配低温度时模型一旦开始复读就自己停不下来（agent 场景表现为"卡住"）

04 · 取舍

都是有意的取舍

  • 串行请求完全串行（单引擎）；超过 --queue-capacity 返回 429。
  • 参数不支持 stop、n>1、logprobs、response_format、JSON Schema 约束解码。
  • tool_choice"required" 和指定函数名不强制，只尊重 "none"。
  • 工具 JSON偶尔带未转义引号：服务端修常见形态，修不好就回退成正文，而不是发出坏调用。
  • 平台Windows 构建（MSVC + CUDA 12.5），其它平台未验证。
  • 范围只支持 qwen35moe 一个架构族；早期项目，不是 llama.cpp 的平替。
